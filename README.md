# Colin Kurniawan - Personal Website

Welcome to the repository for my personal website, hosted at [https://colin-kurniawan.github.io/](https://colin-kurniawan.github.io/). This site serves as a portfolio showcasing my projects, skills, and interests as a Computer Science student.

## About

This website highlights:

- My personal projects and coding experience
- Frontend and backend development skills

The site is designed to be simple, clean, and responsive, providing an easy-to-navigate showcase of my work.

- **Responsive Design** – Works across desktops, tablets, and mobile devices.
- **Contact Section** – Provides ways to reach out or connect professionally.
